## What this is
This code is the "starter code", the basic template that acts as the backbone of all the other projects in the ShadersProjects folder. This code contains files that may not be necessary for every single project, nor does it contain every file necessary for every project, but acts as a decent catch-all, for most of them.

The sphere acts as the "standard" for the template. The project also includes several adjustments to the lighting, including adjusting the ambient, diffuse, and specular, as well as the shininess. This will still be possible in other projects, but may not be shown in the About.md for that project.

Currently, the template cannot be run by normal means.
