# Welcome to my Graphics Projects
This is a collection of projects I created whole learning how to utilize OpenGL. In this repo, I have posted both the source code required for each project and a small explanation of each project, complete with pictures and gifs as necessary.

Many of these projects are somewhat incomplete, to some degree. The purpose with each of these was to experiment with just one or two facets of OpenGL. Since each one was built upon the Template code, this means each project may have been missing features, or even potentially having too many. Rather than clean and polish each of these up, I have decided to post them as they are, both to show my growth over each project, and to dedicate more time to creating new interesting projects.

Feel free to take a look at each project, or even to try them for yourself! All you really need is an updated installation of Visual Studio.

There are two primary categories for the projects here: Graphics and Shaders. , while ShadersProjects are learning about how to utilize shaders (really, just scratching the surface with these).

## Graphics Projects
While technically both categories can be considered part of "graphics", GraphicsProjects are about learning the basics in OpenGL. Basic shape and object creation, manipulation, lighting, animation, the fundamentals necessary to start creating a scene.

Each project should be fully functional to be run using the GraphicsTemplate code. Feel free to try it out and play around with the project yourself!

## Shaders Projects
ShadersProjects uses a basic template code similar to that of the GraphicsTemplate code. However, since the focus was on shaders, each project utilizes different shader files instead to edit each graphical project.

Unfortuantely, these projects do not function as desired at this time. They were built using a proprietary tool from an expert in the field, and are intended to be viewed using said tool.
