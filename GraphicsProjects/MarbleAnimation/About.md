## What this is
This project was essentially the culmination of what I'd learned through the other projects. It creates some objects, textures them, and uses keytime animation to roll them along the tracks, rolling through different lights angles and colors. Once again, no physics are actually present, so the marble movement required manually setting keyframes for each marble. Since they were different size, each one needed its own set of keyframes, as the center of the marble sits a different height above each track. Additionally, since the marbles drop from one track to another, having a smooth landing felt wrong, and it was necessary to add a a custom "wiggle" for each marble. Overall, the animation is far from perfect, but is a neat little scene that's fun to just watch cycle over and over.

To run these projects, copy all files (except for the About.md) from the project folder to the downloaded GraphicsTemplateCode. Replace any files if prompted. Open the solution, build (or rebuild with "Rebuild Solution", as necessary), and run as normal.
