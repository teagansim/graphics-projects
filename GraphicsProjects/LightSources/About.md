## What this is
This project is a test to view how light affects a scene. The light rotates over the scene, causing the objects below to be lit up and cast shadows appropriately. Addditionally, the color of the light being cast can be changed to (R)ed, (B)lue, (G)reen, (Y)ellow, (M)agenta, (C)yan, or back to (W)hite by pressing the corresponding button on the keyboard (the ball indicating the light source stays white, but the light changes appropriately). Since the objects below are red, blue, and green, these different lights demonstrate how shapes light up in different RGBW / CMY lights. The light can also be changed to a (S)potlight, or back to a (P)oint light. Lastly, the orb can be (F)rozen in place temporarily.

To run these projects, copy all files (except for the About.md) from the project folder to the downloaded GraphicsTemplateCode. Replace any files if prompted. Open the solution, build (or rebuild with "Rebuild Solution", as necessary), and run as normal.
