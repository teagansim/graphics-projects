## What this is
This project was a first test at a real "animation". It uses keytime animation to move several objects, including the camera itself, and even changes the color of some objects over time. The light source changes through the whole RGB spectrum as it moves in a circle, the camera moves in a bit of a triangle shape, and two orbs move around the outside of the platform. The orbs also change color, varying their blue-value over time, but with the changing light, it's difficult to see. It's not a very exciting animation, and another project later on used keytime animation to much greater effect.

Technically, the technique used in this project is more like "keyframes" than "keytime", but it uses the same principle. Specific values are set at specific times, and the program applies a "smoothing" to have it gently and cleanly transition from one keyframe to the next. Overall, it creates a pretty effective result for simple animation.

To run these projects, copy all files (except for the About.md) from the project folder to the downloaded GraphicsTemplateCode. Replace any files if prompted. Open the solution, build (or rebuild with "Rebuild Solution", as necessary), and run as normal.
